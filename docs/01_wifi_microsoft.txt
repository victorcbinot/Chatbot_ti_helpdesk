# Fix Wi-Fi connection issues in Windows

Fonte: Microsoft Support
URL: https://support.microsoft.com/en-us/windows/experience/connectivity-networking/fix-wi-fi-connection-issues-in-windows

Aplica-se a: Windows 10 e Windows 11

## Executar o solucionador de problemas de rede

No Windows 11, o aplicativo Get Help possui um solucionador de problemas de Rede e Internet que executa diagnósticos automaticamente e tenta corrigir problemas comuns de conexão.

## Solução geral de problemas

### 1. Verificar o status da conexão de rede

- Selecione os ícones de Rede, Som ou Bateria na barra de tarefas.
- Verifique se o Wi-Fi está ativado.
- Verifique se o nome da rede aparece como "Conectado".
- Se não estiver conectado, selecione uma rede Wi-Fi conhecida e tente conectar-se.

### 2. Verificar o modo avião

- Acesse Configurações > Rede e Internet > Modo avião.
- Verifique se o modo avião está desativado.

### 3. Esquecer e reconectar à rede Wi-Fi

- Acesse Configurações > Rede e Internet > Wi-Fi > Gerenciar redes conhecidas.
- Selecione a rede Wi-Fi e escolha "Esquecer".
- Selecione novamente a rede e informe a senha para conectar.

### 4. Reiniciar o modem e o roteador

Reiniciar o modem e o roteador pode criar uma nova conexão com o provedor de Internet.

Procedimento:
1. Desconecte o roteador da fonte de energia.
2. Desconecte o modem da fonte de energia.
3. Aguarde pelo menos 30 segundos.
4. Reconecte o modem e aguarde até que ele esteja totalmente ligado.
5. Reconecte o roteador e aguarde alguns minutos.
6. Tente conectar o computador novamente.

Se modem e roteador forem o mesmo equipamento, basta seguir o procedimento para o dispositivo único.

### 5. Testar outra frequência Wi-Fi

Muitos roteadores utilizam as bandas de 2,4 GHz e 5 GHz.

- Se as duas redes aparecerem na lista, tente conectar-se à outra frequência.
- Isso pode ajudar a identificar problemas relacionados à banda utilizada.

### 6. Testar a mesma rede em outro dispositivo

Tente conectar outro computador ou celular à mesma rede Wi-Fi.

- Se o outro dispositivo conseguir conectar, o problema provavelmente está relacionado ao dispositivo original.
- Se outros dispositivos também não conseguirem conectar, o problema pode estar relacionado à rede ou ao roteador.

### 7. Executar comandos de rede

Os comandos abaixo podem redefinir a pilha TCP/IP, renovar o endereço IP e limpar o cache DNS.

Abra o Prompt de Comando como administrador e execute, nesta ordem:

```text
netsh winsock reset
netsh int ip reset
ipconfig /release
ipconfig /renew
ipconfig /flushdns
```

Depois, verifique se a conexão foi restaurada.

### 8. Reinstalar o driver do adaptador de rede

Se os passos anteriores não resolverem o problema, pode ser necessário desinstalar o driver do adaptador de rede e reiniciar o computador.

1. Abra o Gerenciador de Dispositivos.
2. Expanda "Adaptadores de rede".
3. Localize o adaptador de rede sem fio.
4. Clique com o botão direito e selecione "Desinstalar dispositivo".
5. Se disponível, marque a opção para remover o driver do dispositivo.
6. Desinstale o dispositivo.
7. Reinicie o computador.

Após a reinicialização, o Windows tentará instalar automaticamente o driver do adaptador de rede.

Antes de desinstalar o driver, é recomendado ter uma cópia do driver disponível. Se o computador não tiver acesso à Internet, o driver pode ser baixado em outro computador e transferido por USB.

### 9. Testar a conexão com o roteador usando ping

É possível verificar se existe comunicação entre o computador e o roteador usando um teste de ping.

1. Abra o Prompt de Comando como administrador.
2. Execute:

```text
ipconfig
```

3. Localize o endereço IP do "Gateway Padrão" da conexão Wi-Fi.
4. Execute:

```text
ping <GatewayPadrão>
```

Exemplo:

```text
ping 192.168.1.1
```

Se houver respostas do gateway, o computador consegue se comunicar com o roteador. Nesse caso, o problema pode estar relacionado ao modem ou ao provedor de Internet.

Se não houver resposta do roteador, pode ser útil testar a conexão diretamente por cabo Ethernet, se disponível. Se a conexão funcionar pelo cabo, o problema provavelmente está relacionado ao Wi-Fi ou ao roteador.

### 10. Desativar economia de energia do adaptador Wi-Fi

1. Abra o Gerenciador de Dispositivos.
2. Expanda "Adaptadores de rede".
3. Clique com o botão direito no adaptador Wi-Fi e selecione "Propriedades".
4. Abra a guia "Gerenciamento de Energia".
5. Desmarque "Permitir que o computador desligue este dispositivo para economizar energia".

### 11. Verificar atualizações do Windows

Acesse:

Configurações > Windows Update > Verificar se há atualizações.

Baixe e instale as atualizações disponíveis.

### 12. Reiniciar o computador

Algumas atualizações e alterações de configuração exigem uma reinicialização.

Salve o trabalho, feche os aplicativos e reinicie o computador.

### 13. Redefinir a rede

A redefinição de rede deve ser usada como uma das últimas tentativas.

Ela remove os adaptadores de rede instalados e suas configurações e, após a reinicialização, reinstala os adaptadores e restaura as configurações para os valores padrão.

No Windows 11:
Configurações > Rede e Internet > Configurações avançadas de rede > Redefinição de rede.

No Windows 10:
Configurações > Rede e Internet > Status > Redefinição de rede.

Depois:
1. Selecione "Redefinir agora".
2. Confirme a operação.
3. Aguarde o computador reiniciar.
4. Verifique se a conexão foi restaurada.

Após uma redefinição de rede, pode ser necessário reinstalar e configurar softwares de rede, como clientes VPN ou switches virtuais do Hyper-V.

## Problemas comuns de Wi-Fi

### Internet conectada, mas velocidade muito baixa

- Verifique a intensidade do sinal e aproxime o dispositivo do roteador, se necessário.
- Verifique se existem obstáculos entre o dispositivo e o roteador.
- Abra o Gerenciador de Tarefas e verifique processos que estejam consumindo muita largura de banda.
- Conecte outro dispositivo ao Wi-Fi para verificar se o problema também ocorre nele.
- Se o problema persistir em outros dispositivos, o roteador pode precisar de manutenção ou substituição.

### Opção de Wi-Fi ausente

Se a opção de Wi-Fi não aparecer nas configurações:

- Verifique se o notebook possui um interruptor físico de Wi-Fi e se ele está ativado.
- Abra o Gerenciador de Dispositivos > Adaptadores de rede.
- Localize o adaptador Wi-Fi e verifique se ele está habilitado.
- Para reiniciar o serviço WLAN:
  1. Pressione Win + R.
  2. Digite `services.msc`.
  3. Pressione Enter.
  4. Localize "WLAN AutoConfig".
  5. Clique com o botão direito e selecione "Reiniciar".

### Wi-Fi desconectando frequentemente

- Verifique as configurações de energia do adaptador sem fio.
- Em Opções de Energia, procure as configurações do adaptador sem fio e defina o modo de economia de energia como "Desempenho máximo".
- Verifique o canal utilizado pelo roteador. Alterar o canal pode reduzir interferências.

### Wi-Fi conectado, mas sem acesso à Internet

Quando o computador está conectado à rede local, mas não consegue acessar a Internet:

- Desative e reative o Wi-Fi e reconecte-se à rede.
- Renove a configuração de IP:

```text
ipconfig /release
ipconfig /renew
```

- Limpe o cache DNS:

```text
ipconfig /flushdns
```

- Verifique as configurações de proxy em Configurações > Rede e Internet > Proxy.
- Desative configurações manuais de proxy, se não forem necessárias.
- Verifique o endereço IP. Um endereço no formato `169.254.x.x` pode indicar que o Windows não conseguiu obter um endereço IP do roteador.
- Verifique se o DHCP está habilitado no roteador quando a rede não utiliza endereços IP estáticos.
- Verifique o servidor DNS:

```text
ipconfig /all | findstr /c:"DNS Servers"
```

Depois, teste a comunicação com o servidor DNS usando:

```text
ping <endereço_do_servidor_DNS>
```

### Problemas de autenticação Wi-Fi

Quando não é possível conectar à rede devido a erros de senha:

- Verifique se a senha está correta.
- Reinicie o roteador.
- Se necessário, consulte a documentação do roteador para restaurar as configurações de fábrica.
- Verifique se o firmware do roteador está atualizado.

### Adaptador de rede reconhecido, mas nenhuma rede Wi-Fi encontrada

Possíveis causas e verificações:

- O interruptor físico de Wi-Fi do notebook ou tablet pode estar desligado.
- O Wi-Fi pode estar desativado nas configurações do Windows.
- O adaptador pode não ser compatível com a frequência utilizada pela rede. Por exemplo, o adaptador pode suportar apenas 2,4 GHz enquanto a rede utiliza 5 GHz.
- O driver do adaptador pode estar configurado para não permitir a frequência utilizada pela rede.

Para verificar a configuração do adaptador:
1. Abra o Gerenciador de Dispositivos.
2. Acesse Adaptadores de rede.
3. Abra as propriedades do adaptador Wi-Fi.
4. Acesse a guia "Avançado".
5. Procure configurações como "Wireless Mode" ou "Band".
6. Verifique se a frequência utilizada pela rede é permitida.
